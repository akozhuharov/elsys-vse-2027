## Примерни програми

Всяка част завършва с три примерни програми. Кодът им стои и отделно в
[`examples/`](./examples/), подредени по теми, и се пуска директно:

```
python3 examples/01-introduction/01-dress-advisor.py
```

## Визуализатор

[`visualizer.html`](./visualizer.html) показва всички 21 програми **ред по ред** —
кой ред се изпълнява в момента, как се променят променливите, какво е излязло на
екрана, стека от извикани функции и съдържанието на файловете. Отваря се с двойно
кликане, не иска интернет (освен за стиловете) и не иска инсталиран Python.

Управление: `→` напред, `←` назад, `space` автоматично пускане, `R` от начало.

### Как се обновява

Стъпките не са написани на ръка — записват се с истинско изпълнение на програмите
(`sys.settrace`). След промяна в примерите:

```
python3 tools/trace.py             # записва стъпките -> tools/trace-data.json
python3 tools/build_visualizer.py  # вгражда ги във visualizer.html
python3 tools/sync_examples.py     # обновява секциите "Примерни програми" в .md
```
