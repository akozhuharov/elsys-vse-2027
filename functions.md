# Функции
## Дефиниция
Дефиниция на функции става с ключова дума def следвана от име на функцията и променливи наречени аргументи:
```python
def add(a, b):  # аргументите са a и b и са задължителни
    return a + b  # return връща резултата от събирането - трябва да се присвои на променлива след извикаването на функцията

result = add(4, 5)  # присвояваме резултата върнат от return
print(result)
```
## Аргументи
В примера ни аргументите а и b са позиционни, т.е. при извикване е важно позицията на аргумента
### Задължителни
Както в примера по-горе а и b са задължителни и ако не се подаддат при извикване интерпретатора ще върне грешка
```python
add(4)  # error
```

### Стойност по подразбиране
Може да дадем на определен аргумент стойност по подразбиране, като по този начин може да изпуснем подаването на този аргумент при самото извикване на функцията
```python
def add(a, b=0):  # стойността на b e 0 и ако не бъде подадена стойност при извикане ще се ползва 0 
    return a + b
result = add(4)
print(result)  # 4
```

### Неограничени аргументи
Когато искаме функцията да поддържа неограничен брой позиционни аргументи може да се ползва *args (името на променливата е произволно, но е прието да се ползва args). Това ще бъде списък, който вътре в функцията може да бъде обходен/достъпен

```python
def sum(*args):  # args е списък от стойностите в реда им на подаване
    s = 0
    for i in args:
        s += i

result = sum(5, 6, 9, 1)
print(result)  # 21
```

### Неограничени наименовани аргументи
Т.нар. keyword args се дефинират с 2 звезди(**) и при извикването на функцията трябва също да бъдат подадени с имената. Пример:
```python
def fun(**kwargs):
    for key, val in kwargs.items():
        print(k, val)
fun(a=3, b=4, c=5)
# a 3
# b 4
# c 5
```

### 1. Площ на правоъгълник
*задължителни аргументи и стойност по подразбиране*

```python
# Площ на правоъгълник - задължителни аргументи и стойност по подразбиране
def area(width, height):          # и двата аргумента са задължителни
    return width * height


def describe(name, unit="кв.м"):  # unit има стойност по подразбиране
    return name + " " + unit


a = area(4, 5)
print("Площ:", a)

b = area(height=2, width=10)      # с имена редът няма значение
print("Площ:", b)

print(describe("20"))             # unit не е подаден -> "кв.м"
print(describe("20", "кв.км"))    # тук подаваме свой unit
```

Изход:
```
Площ: 20
Площ: 20
20 кв.м
20 кв.км
```

### 2. Статистика с *args
*неограничен брой позиционни аргументи*

```python
# Статистика с *args - неограничен брой позиционни аргументи
def stats(*args):
    if len(args) == 0:
        return 0, 0, 0            # функция може да върне няколко стойности
    total = 0
    biggest = args[0]
    for number in args:
        total += number
        if number > biggest:
            biggest = number
    return total, total / len(args), biggest


s, avg, mx = stats(5, 6, 9, 1)    # разпакетваме трите върнати стойности
print("сума:", s, "средно:", avg, "макс:", mx)

print(stats(10))
print(stats())
```

Изход:
```
сума: 21 средно: 5.25 макс: 9
(10, 10.0, 10)
(0, 0, 0)
```

### 3. Профил с **kwargs
*и функция, която вика друга функция*

```python
# Профил с **kwargs - и функция, която вика друга функция
def initials(full_name):
    parts = full_name.split()
    letters = ""
    for part in parts:
        letters += part[0]        # първата буква на всяка дума
    return letters


def profile(full_name, **kwargs):
    print("Име:", full_name)
    print("Инициали:", initials(full_name))   # извикваме другата функция
    for key, value in kwargs.items():
        print(" ", key, "=", value)
    return len(kwargs)


count = profile("Atanas Kozhuharov", city="Sofia", age=16, grade=9)
print("Допълнителни полета:", count)

profile("Ivan Ivanov")            # kwargs може да е празен
```

Изход:
```
Име: Atanas Kozhuharov
Инициали: AK
  city = Sofia
  age = 16
  grade = 9
Допълнителни полета: 3
Име: Ivan Ivanov
Инициали: II
```
